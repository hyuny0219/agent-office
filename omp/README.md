# omp-agent-office

oh-my-pi(omp) 확장입니다. 서브에이전트(`task` 도구)를 부서 직원으로 받아 평가·결재·인사 기록·업무 노트·토큰 비용을 남기고, 입력창 위에 2단 패널(왼쪽 사무실 목록 | 오른쪽 사내 메신저)과 (켜면) 걸어 다니는 사무실 평면도를 보입니다. 오른쪽 사이드바로도 볼 수 있습니다(`/office side`).

Claude Code판(agent-office 플러그인)과 판단 코드(`core/`)는 같지만, 이 패키지는 따로 배포되고 인사 기록도 따로 남습니다(`~/.omp/agent-office/hr.json`, 환경 변수 `AGENT_OFFICE_HOME`으로 바꿀 수 있음).

## 설치

omp의 플러그인으로 설치합니다(Claude Code의 `/plugin install`과 같은 자리). 한 번 설치하면 omp를 켤 때마다 저절로 불러옵니다.

```sh
# 사내 레지스트리에 올린 패키지에서(레지스트리는 ~/.npmrc나 bunfig로 지정)
omp plugin install omp-agent-office
# 또는 받은 .tgz·폴더에서
omp plugin install ./omp-agent-office-<버전>.tgz
omp plugin list            # 설치 확인
omp plugin uninstall omp-agent-office
```

플러그인으로 설치했으면 `omp -e …`로 따로 불러오지 마세요(두 번 불러와집니다).

## 쓰는 법

| 명령 | 하는 일 |
| --- | --- |
| `/office` | 입력창 위에 사무실 평면도 켜고 끄기(목록은 늘 보임) |
| `/office side` | 오른쪽 사이드바(사무실 목록·사내 메신저, `/office`로 평면도를 켜 두었으면 평면도도 — 그때는 사이드바를 평면도가 들어가는 74칸으로 넓힘) 켜고 끄기(시작부터 켜려면 `AGENT_OFFICE_SIDE=1`). 터미널 폭 120칸 이상일 때 보이고 그동안 입력창 위 패널은 숨깁니다. **떠 있는 동안 omp 전역 단축키(Ctrl+O 도구 출력 펼치기·기록 검색·thinking 접기·외부 편집기 등)는 쉽니다**(일반 터미널에서 겹쳐 띄운 화면의 한계). 입력·승인 창은 그대로 됩니다 |
| `/office menu` | 메뉴 화면(온 화면, 마우스로도 누름): `0` 사무실(평면도와 목록: 사람·이름표·책상 명패나 목록 줄을 누르면 그 직원의 인사카드) · `1` 인사 명부 · `2` 일간 보고 · `3` 주간 보고 · `4` 예산 · `5` 설정 · `6` 지침 · `7` 기록(`5`에서 `a` 결재 · `r` 조직 개편 · `m` 인사 메모 · `t` 교육 효과 측정을 켜고 끄고, 부서 배치 표를 봄), `q`·Esc 닫기 |
| `/office export [json\|csv] [<폴더>]` | 인사 기록 내보내기: `json`(기본)은 통째로, `csv`는 업무 기록·월별 요약 두 파일(엑셀용). 폴더를 주지 않으면 `~/.omp/agent-office/exports/`에 |
| `/office dept [<종류> <부서>\|<종류> reset]` | 에이전트 종류의 부서 배치(기본: `task` 개발팀, `scout`·`seance` 조사팀, `sonic` 지원팀, 표에 없으면 지원팀) |
| `/office hr [<별칭>]` | 인사 명부, 인사카드 |
| `/office report [today\|week]` | 일간·주간 보고 |
| `/office playbook [<부서> adopt <n\|all>\|<부서> drop <n>]` | 부서 지침(에이전트 개선): 반복되는 흠으로 만든 후보 채택·빼기, 전후 비교(메뉴 `6`에서 보기) |
| `/office rate <별칭> good\|bad\|clear` | 가장 최근 일에 대표 평가 |
| `/office budget [<부서> <달러>\|<부서> <토큰 수>\|<부서> off]` | 부서 하루 비용 한도(`5`, `$5`)나 토큰 수 한도(`2M`, `500k`): 넘으면 하루 한 번 알리고, 그 부서에 새 일(`task`)을 맡길 때 계속·이번만·맡기지 않기를 묻는다 |
| `/office approval\|reorg\|hr on\|off` | 결재·조직 개편·인사 메모 켜고 끄기 |

- 인사 메모(담당·지난 기록·부서가 반복한 실수·업무 노트)는 그 서브에이전트의 시스템 프롬프트에만 붙고, 메인이 보낸 지시는 건드리지 않습니다.
- 계획 검토: omp의 계획 검토 창이 열리면(plan 모드에서 계획을 내면) 기획팀장이 결재자 모델(Haiku)로 검토해 적합·보완을 알리고 사내 메신저에 남깁니다(창을 붙잡지 않습니다). 보완인데 실행을 고르면 그 의견을 메인의 다음 도구 결과 뒤에 붙이고, 다시 쓰기·저장·닫기면 버립니다. 결재를 끄면(`/office approval off`) 검토하지 않습니다.
- 메뉴 화면은 온 화면(보조 화면)으로 떠서 그동안 omp가 마우스를 넘겨 줍니다. 맨 위 메뉴, 사무실 평면도의 사람·이름표·책상 명패, 목록·명부 줄을 누르면 그 화면이나 인사카드로 갑니다. 떠 있는 동안은 터미널의 글자 끌어 고르기가 쉽니다(닫으면 돌아옴).
- 근태: 서브에이전트가 같은 오류를 3번 연달아 내거나(헛손질) 같은 도구를 같은 입력으로 4번 되풀이하면(제자리걸음, `wait`는 빼고) omp 알림으로 알리고 인사 기록에 남기며, 인사 메모가 켜져 있으면 그 도구 결과 뒤에 그만두고 다른 길을 찾으라는 알림을 붙입니다. 20분 넘게 일하면 야근으로 한 번 알립니다.
- 교육 효과 측정: 실수 목록을 붙일 업무 5건에 한 건은 목록만 빼고 보내(비교군) 재발률을 견줍니다(Claude Code판과 같은 규칙, `/office hr ab on|off`).
- 결재는 결재자 모델(Haiku)을 한 번 부르며, 반려 의견은 메인이 `wait`(또는 `task`)로 결과를 받을 때 그 뒤에 붙습니다.
- 토큰 비용은 omp가 알려 주는 사용량을 모델별 API 정가로 어림한 값입니다.
- 예산을 넘은 부서에 `task`로 일을 맡기려 하면 선택 창을 띄웁니다. "맡기지 않기"를 고르거나 창을 닫거나 물을 수 없는 실행(`omp -p`)이면 그 `task` 호출을 막고 까닭을 모델에 돌려줍니다. 한 번의 `task`에 여러 일이 있으면 부서마다 한 번 묻습니다.
- 새 지침 후보가 오르면 omp 알림과 사내 메신저로 한 번 알리고, 메뉴 `6`(또는 `/office playbook`)을 볼 때까지 입력창 위 패널·사이드바 맨 위에 `● 새 지침 후보 N건` 줄을 둡니다.
- 끝낸 일 기록은 최근 300건을 두고, 밀려난 오래된 일은 월별 요약으로 접어 둡니다(메뉴 `7`).

## 사내 모델(GLM 등)만 쓸 때

Claude 모델 없이 사내 서버 모델(예: GLM-5.2-NVFP4)만 쓸 수 있어도 그대로 돕니다.

- **결재자 모델**: 환경 변수 `AGENT_OFFICE_APPROVER`(모델 이름이나 omp 역할 별칭)로 고른 모델 → 없으면 Haiku → 그것도 없으면 지금 세션 모델 순으로 고릅니다. 사내 omp라면 따로 정하지 않아도 세션 모델(GLM)이 결재·계획 검토를 합니다. 결재를 부를 때는 추론을 끄고(`disableReasoning`), 답에 `<think>…</think>`가 섞여 와도 걷어 내고 읽습니다.
- **기다리는 시간**: Haiku는 8초, 그 밖의 모델은 30초. `AGENT_OFFICE_APPROVAL_TIMEOUT_MS`로 바꿉니다. 넘기면 그 결재는 보류입니다.
- **비용**: Claude 가격표에 없는 모델은 omp 모델 목록에 적힌 가격(`cost`)으로 셉니다. 가격이 없거나 0인 사내 모델의 토큰은 "가격 모름"으로 적혀 달러 예산이 차지 않으니, **토큰 수 예산**(`/office budget 개발팀 2M`)으로 잽니다.
- **모델 이름**: 패널에는 제공자와 양자화 꼬리를 떼고 `GLM 5.2`처럼 짧게 보입니다.

```sh
# 예: 결재는 사내 GLM으로, 기다리는 시간은 1분
AGENT_OFFICE_APPROVER=glm-5.2 AGENT_OFFICE_APPROVAL_TIMEOUT_MS=60000 omp
```

## 판 차이(Claude Code판과 다른 것)

입력창 위 패널·사이드바의 평면도는 누를 수 없습니다(omp는 겹쳐 띄운 화면이 없을 때 마우스를 자기 설정 `tui.mouse`로만 받고 확장에 넘기지 않음): 누르려면 `/office menu`의 `0 사무실`에서 누르세요.

## 개발

화면 줄 만들기(`omp/view.ts`: 입력창 위 패널·사이드바·메뉴)는 omp에 기대지 않는 순수 함수라 omp 없이 시험합니다.

```sh
npx -p typescript tsc -p omp/tsconfig.json   # 타입 검사
bun test omp/                                 # 화면 줄 테스트
bun scripts/snap.ts --check                   # 화면 스냅샷(snapshots/omp-*.txt)
node scripts/pack-omp.mts --pack              # 배포 패키지
```
